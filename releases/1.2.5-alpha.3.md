New
- Devices page on the Dynamic Island (#102): connected wireless peripherals with battery cards.
- Collapsed strip reading “Lowest device battery” (off by default) and a Devices settings page (page size, low-battery threshold, hide individual devices).
- AJAZZ / AJ179 read-only battery (dongle 249A:5C2F): percent, online / asleep, device name (e.g. M041). Sleep keeps the last percent (never a false 0%); the device card and tooltip show “Sleeping”.

Notes
- Fork prerelease for testing the devices UI plus AJ179. Stacks upstream 1.2.5-alpha.1 with #101 core, #102 UI, and AJ179 (#200 toward MoFeng2223/BrimDeck).
- Charging icon / DPI / report rate on the island are still deferred. Compact-strip gray styling for asleep may follow later.
- Install and plug in the receiver on Windows to confirm readings.

新功能
- 灵动岛「设备」页（#102）：已连接无线外设的电量卡片。
- 收起行读数「设备最低电量」（默认关闭），以及「设备」设置页（页面大小、低电量阈值、逐个隐藏设备）。
- 黑爵 / AJ179 只读电量（接收器 249A:5C2F）：电量 %、在线/休眠、设备名（如 M041）。休眠保留上次电量（不误报 0%）；卡片与提示显示「休眠」。

说明
- 本仓库预发布，用于试设备页 + 黑爵电量。基于上游 1.2.5-alpha.1，叠加 #101 读取层、#102 UI 与 AJ179（向上游 PR #200）。
- 充电图标 / DPI / 回报率仍延后。收起行休眠灰显可能后续再补。
- 请在 Windows 安装并插上接收器自行确认读数。
