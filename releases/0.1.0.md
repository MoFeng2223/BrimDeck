BrimDeck 的第一个版本。

- 悬浮面板：常驻屏幕顶部中央，提供刘海、胶囊、指示条三种收起形态，鼠标停留时展开。窗口最大化时默认改为指示条，全屏时默认隐藏。
- AI 用量：显示 Claude、Codex、Antigravity、Cursor、ZCode 的配额、重置时间和套餐，以及今日与 7 天的 Token 用量和费用估算。
- 手动配额来源：支持智谱 GLM、Z.ai GLM、New API、Sub2API 和自定义 JavaScript 脚本。
- 模型明细：按应用和模型查看 Token 用量与费用，可按今日、7 天、30 天或自选日期筛选。
- 音乐：显示网易云音乐、QQ 音乐及其他播放器的曲目、封面、歌词和进度，提供播放控制和律动条。
- 设置：最多 7 个看板条目，可分别设置配额来源、统计应用、名称和颜色；界面支持简体中文和英文。
- 安装与更新：提供安装包，打开设置时检查新版本，可在应用内下载、校验并安装。
