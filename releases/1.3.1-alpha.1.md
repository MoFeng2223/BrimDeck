New
- New CodeAgent quota and usage source.
- New Command Code quota and usage source, and a Command Code API source with a key entered by hand.
- New WorkBuddy (China) and WorkBuddy AI (international) quota and usage sources. Credits are read after you sign in through the browser in Settings.
- New Xiaomi MiMo quota and usage sources: the desktop subscription, automatic reading, and Xiaomi MiMo API and Xiaomi MiMo Token Plan with keys entered by hand.
- New "Lyric area follows the line length" and "Title area follows the title length" switches (Settings > Style > When collapsed), off by default.
- New "Apply font to settings window" switch (Settings > General > Appearance and language), off by default. When it is on, the settings window also uses the chosen interface font.
- New "Keep history after exit" switch for the clipboard (Settings > Clipboard). When it is on, the history is no longer cleared when BrimDeck exits, and entries older than "Keep for" are deleted.
- Local songs in QueMusic are supported: lyrics are read first from a lyrics file in the song's folder or from the lyrics embedded in the file.

Improvements
- Any number of AI quota apps can be added, and up to 7 are shown at once.
- Newly added apps use Codex as their quota source and usage app by default.
- When updating, the installer backs up the old version first and restores it if installing the new version fails or is canceled. When an in-app update fails, BrimDeck asks whether to try again.
- Battery levels of Razer devices are read while Razer Synapse is running.
- When the vertical capsule is docked to the left or right edge of the screen, device battery levels are shown one device per line and no longer scroll sideways.
- Reading the token details of a merged Cursor plan takes fewer requests. If reading is interrupted, what has been read is kept.
- Some displayed content is improved.
- The window layer log no longer writes the same record repeatedly.
- The clipboard history and the file transfer list are saved without encryption, so saving is faster when there are many entries. Formatting copied from web pages, Word and other apps is stored separately on disk, which uses less memory.

Fixes
- Fixed battery levels not being read from the ATK charging dongle and the Razer Basilisk Ultimate.
- Fixed GPU readings briefly being too high when the panel expands.
- Fixed the file transfer list flickering while scrolling.
- Fixed closing the quota source drop-down also expanding or collapsing that app's row.
- Fixed readings that are turned off leaving empty lines in the column when the capsule is docked to the left or right edge of the screen.
- Fixed the fitted length being shorter than the content when the capsule is docked to the left or right edge of the screen and BrimDeck's scale is 150%.

新功能
- 新增 CodeAgent 额度与统计来源。
- 新增 Command Code 额度与统计来源，以及手动填写密钥的 Command Code API 来源。
- 新增 WorkBuddy（国内版）和 WorkBuddy AI（国际版）额度与统计来源。在设置中通过浏览器登录后读取积分。
- 新增 Xiaomi MiMo 额度与统计来源，包括桌面订阅、自动读取，以及手动填写密钥的 Xiaomi MiMo API 和 Xiaomi MiMo Token Plan。
- 新增“歌词区域随歌词长度变化”和“歌名区域随歌名长度变化”开关（设置 > 样式 > 收起时），默认关闭。
- 新增“字体应用到设置窗口”开关（设置 > 常规 > 外观与语言），默认关闭。开启后，设置窗口也使用所选的界面字体。
- 剪贴板新增“退出后保留历史”开关（设置 > 剪贴板）。开启后，退出 BrimDeck 时不再清除记录，超过“保存时长”的记录会自动删除。
- 新增适配 QueMusic 中的本地歌曲时，优先读取歌曲同目录下的歌词文件或文件内嵌的歌词。

改进
- AI 配额应用的数量不再受限，最多同时显示 7 个。
- 新添加的应用默认使用 Codex 作为配额来源和统计应用。
- 安装更新时会先备份旧版本，新版本安装失败或被取消时恢复旧版本。应用内更新出错时，会询问是否重试。
- 雷蛇 Synapse 运行时也能读取雷蛇设备的电量。
- 竖向胶囊贴靠在屏幕左侧或右侧时，设备电量改为每个设备占一行，不再横向滚动。
- 读取 Cursor 合并套餐的 Token 明细时请求次数更少；读取中断时，已读取的部分会保留。
- 部分显示内容优化。
- 窗口层级日志不再反复写入相同的记录。
- 剪贴板记录与文件中转列表改为不加密保存，记录很多时保存更快。网页、Word 等复制时附带的格式单独保存在磁盘上，内存占用更少。

修复
- 修复 ATK 充电接收器和雷蛇 Basilisk Ultimate 读不到电量的问题。
- 修复展开面板时，GPU 读数短暂偏高的问题。
- 修复文件中转列表滚动时闪烁的问题。
- 修复配额来源下拉框收起时，同时展开或收起该应用行的问题。
- 修复胶囊贴靠在屏幕左侧或右侧时，已关闭显示的系统读数在竖列中留下空行的问题。
- 修复胶囊贴靠在屏幕左侧或右侧、BrimDeck 缩放为 150% 时，自适应长度比内容短的问题。
