# 邮箱

连接邮箱后，BrimDeck 在新邮件到达时发出一条通知：

- 通知显示发件人、主题和正文开头，与其他通知一样出现在岛上和通知页。
- 邮件中的验证码可以用“复制验证码”按钮直接复制（需要打开 设置 › 灵动提示 › 提示方式 › 遮住验证码）。
- “打开邮箱”按钮在浏览器中打开该邮箱的网页版。

已经使用 Outlook、Foxmail、Thunderbird 等邮件客户端，或在浏览器中开启了网页邮箱通知的，不需要连接邮箱：这些 Windows 通知本来就会显示在通知页（见[灵动提示](notices.md)）。连接邮箱适合不想一直开着邮件客户端的情况。

## 添加邮箱

1. 打开 设置 › 灵动提示 › 邮箱，点“添加邮箱”。
2. 选择邮箱服务。
3. 按窗口中的步骤，在邮箱的网页版生成授权码（或应用专用密码），填入邮箱地址和授权码，点“连接”。

BrimDeck 先用填写的内容登录一次，登录成功后才保存这个邮箱。最多可添加 8 个邮箱。

| 邮箱服务 | 填写什么 | 在哪里取得 |
|---|---|---|
| QQ 邮箱（qq.com、foxmail.com） | 授权码 | QQ 邮箱网页版“设置 › 账号与安全”，开启 IMAP/SMTP 服务并生成授权码 |
| 网易邮箱（163.com、126.com、yeah.net） | 授权码 | 网易邮箱网页版“设置 › POP3/SMTP/IMAP”，开启 IMAP/SMTP 服务 |
| 腾讯企业邮 | 邮箱密码；开启了“安全登录”的账号填客户端专用密码 | 企业邮箱网页版“设置 › 收发信设置”开启 IMAP 服务；专用密码在“设置 › 邮箱绑定”生成 |
| 新浪邮箱 | 授权码 | 新浪邮箱网页版“设置 › 客户端pop/imap/smtp” |
| iCloud 邮件 | App 专用密码 | account.apple.com 的“登录和安全 › App 专用密码”，需要已开启双重认证 |
| Gmail | 应用专用密码 | myaccount.google.com/apppasswords，需要已开启两步验证；工作或学校账号可能没有这一项 |
| 其他邮箱 | 密码或授权码，以及 IMAP 服务器地址 | 邮箱的网页版设置或管理员 |

Outlook、Hotmail 和 Microsoft 365 邮箱不接受密码或授权码，需要登录 Microsoft 账户连接：

1. 在 Outlook 网页版右上角打开“设置”，进入“邮件 › 转发和 IMAP”，打开“让设备和应用使用 IMAP”。Microsoft 说明个人账户的 IMAP 默认关闭；已经打开的可以跳过这一步。工作或学校账户的 IMAP 由单位管理员控制。
2. 在 BrimDeck 中选择 Outlook，点“在浏览器中登录”。
3. 在浏览器打开的 Microsoft 页面登录要连接的账户，点“接受”。页面显示“登录完成”后回到 BrimDeck。BrimDeck 连接的是你在这个页面上登录的账户的邮箱。

授权页面把这项权限写作“你的邮件的读写访问权限”，这是 Microsoft 对 IMAP 权限的统一说法，没有只读的版本可选。BrimDeck 以只读方式打开收件箱，不修改、移动或删除邮件。

BrimDeck 没有经过 Microsoft 的发布者验证，登录页面会把它的发布者显示为“未验证”。工作或学校账户如果显示需要管理员批准，需要请单位的管理员批准一次。BrimDeck 只保存 Microsoft 给出的登录凭据，不保存账户密码。

只支持 993 端口的加密连接（IMAP over TLS）。

## 邮箱列表

每个邮箱一行，显示连接状态：

| 状态 | 含义 |
|---|---|
| 已连接 | 正在接收新邮件 |
| 正在连接… | 正在登录 |
| 连接中断，稍后自动重连 | 网络或服务器暂时不可用。BrimDeck 依次等待 5 秒、15 秒、1 分钟、5 分钟后重试 |
| 登录被拒绝 | 服务器拒绝了登录：授权码已失效（例如修改了邮箱密码）或 IMAP 服务被关闭。BrimDeck 不再自动重试，以免多次失败导致账号被限制；点“重新填写”换一个授权码，或点“重试” |

每一行还可以：

- 选择这个邮箱的提示等级（默认、等级 1 至 3、只进通知页），含义见[灵动提示](notices.md#提示等级)。
- 用开关暂停接收。
- 点右侧的 × 移除邮箱，同时删除保存在本机的授权码。

## 何时提醒

- 只提醒连接之后新到的、未读的邮件。添加邮箱时、每次启动 BrimDeck 时收件箱里已有的邮件不提醒。
- 电脑睡眠或断网期间到达的邮件，在恢复连接后记入通知页并标为未读，不再弹出（收到时已超过 10 分钟的邮件都按这种方式处理）。
- 每封邮件在通知页单独一行，同一发件人的多封邮件不合并。
- 一次最多提醒最新的 20 封。
- 灵动通知的两个开关都关闭时，邮箱不连接。

服务器支持推送（IMAP IDLE）时，新邮件通常在几秒内提醒；BrimDeck 另外每 60 秒检查一次，因为有些邮箱不一定推送。

## 隐私

- BrimDeck 直接连接邮箱自己的服务器，不经过任何中转服务。
- 只读取收件箱中新邮件的发件人、主题、时间和正文开头（纯文本约 500 字节，网页格式的邮件最多读取 16 KB 后提取文字）。不下载附件，不读取其他文件夹。
- 以只读方式打开收件箱，不改变邮件的已读状态，不发送、移动或删除邮件。
- 授权码使用 Windows 为当前用户提供的加密（DPAPI）保存在 `%LOCALAPPDATA%\BrimDeck\secrets.dat`，`settings.json` 中只有邮箱地址和服务名称。导出的配置不包含授权码，导入到另一台电脑后需要重新填写。
- 邮件通知与其他通知一样进入通知历史，在本机加密保存，保留时间见[灵动提示](notices.md#隐私)。

IMAP 连接使用 MailKit（MIT 许可证，见 ThirdPartyNotices.txt）。
