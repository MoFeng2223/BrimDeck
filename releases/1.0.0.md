The first stable release of BrimDeck.

- Collapsed styles: stays at the top center of the screen as a notch, a capsule or an indicator, and opens when the pointer moves over it. By default it becomes the indicator when a window is maximized and hides in full screen.
- AI quotas: reads quota usage and reset times for Claude, Codex, Cursor, Antigravity and ZCode from this PC automatically, with no keys to enter. Up to 7 columns at once. When a quota reaches 70% or 90%, the collapsed view shows a notice for 5 seconds.
- Manual quota sources: Zhipu GLM, Z.ai GLM, New API and Sub2API relays, and custom JavaScript scripts.
- Usage: tokens and estimated cost for today and the last 7 days, with details by model.
- Music: works with players that use Windows media controls, with extra support for NetEase Cloud Music and QQ Music. Shows the song, synced lyrics and progress, with playback controls.
- In-app updates: checks for a new version when Settings opens, then downloads, verifies and installs it in the app.
- Interface languages: English and Simplified Chinese.

BrimDeck 的第一个正式版本。

- 收起形态：停在屏幕顶部中央，提供刘海、胶囊、指示条三种样式，鼠标移入即展开。默认在窗口最大化时改为指示条，全屏时自动隐藏。
- AI 配额：自动读取本机 Claude、Codex、Cursor、Antigravity、ZCode 的配额使用率与重置时间，无需填写密钥；最多同时显示 7 列。配额达到 70% 或 90% 时，收起形态显示 5 秒提醒。
- 手动配额来源：支持智谱 GLM、Z.ai GLM、New API 与 Sub2API 中转站，以及自定义 JavaScript 脚本。
- 用量统计：显示今日与 7 天的 Token 用量和费用估算，可按模型查看明细。
- 音乐：支持接入 Windows 系统媒体控制的播放器，并额外支持网易云音乐和 QQ 音乐；显示歌曲信息、同步歌词与进度，提供播放控制。
- 应用内更新：打开设置时检查新版本，可在应用内下载、校验并安装。
- 界面语言：简体中文与英文。
