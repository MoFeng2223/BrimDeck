New
- Added DeepSeek Harness and DeepSeek as quota sources, and added DeepSeek Harness token statistics.
- Claude quotas can now be read only from this PC.
- The notch and capsule can show the time, with nine styles and a choice of custom or gradient colors.
- Added a "Right-click opens settings" switch, on by default. It applies only to the expanded panel.

Fixes
- Fixed display issues on the quota and statistics settings pages.
- Fixed display issues in the expanded panel.

新功能
- 新增 DeepSeek Harness 和 DeepSeek 配额来源，并支持统计 DeepSeek Harness 的令牌用量。
- Claude 配额支持仅从本机读取。
- 刘海和胶囊可以显示时间，提供九种样式，颜色可以自定义，也可以使用渐变色。
- 新增“右键点击打开设置”开关，默认开启，只在展开面板上生效。

修复
- 修复配额与统计设置页面的部分显示问题。
- 修复展开面板中部分内容的显示问题。
