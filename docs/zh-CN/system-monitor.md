# 系统监控的读数

系统监控页显示 CPU、GPU、内存、网络、硬盘、温度、功耗、电池和帧率。本文说明各项读数的来源与限制。相关设置在“设置 › 显示与读数”中。

所有读数只在本机读取和显示，不保存、不上传。除特别说明外，读取不需要管理员权限，也不安装驱动。

## 读数一览

| 读数 | 默认 | 开关位置 | 说明 |
| --- | --- | --- | --- |
| CPU、内存、下载、上传 | 显示 | 展开时显示的监控项 | CPU 另有每个核心的使用率 |
| GPU | 显示 | 展开时显示的监控项 | 有多块显卡时可选择显示哪一块 |
| 占用最高的应用 | 显示 | 展开时 › 显示进程列表 | 按 CPU 或内存排序，点击应用查看详情 |
| 硬盘 | 显示 | 展开时显示的监控项 › 硬盘 | 只列内置硬盘 |
| 整机功耗与本机电池 | 显示 | 展开时显示的监控项 › 功耗与电池 | 没有电池的电脑不显示电池 |
| 温度 | 不显示 | 展开时 › 显示温度 | CPU、GPU 和固态硬盘 |
| 帧率 | 不显示 | 展开时显示的监控项 › 帧率 | 首次开启需要授权 |

刘海与胶囊中显示哪些读数，在“收起时”一节中选择。

## 选择展开页显示什么

“展开时显示的监控项”是一张表，每行是一个读数：CPU、GPU、内存、下载、上传、帧率、硬盘、功耗与电池。勾选“显示”决定展开页是否显示它；拖动行首的手柄，或在行内按 Alt+↑/↓，调整它在页面上的先后。进程列表有单独的“显示进程列表”开关，位置由页面大小决定。

- 这里的勾选只管展开页，“收起时”的勾选只管刘海和胶囊，两处互不影响。
- 快捷预设：全部（帧率保持原状）、简洁（CPU、内存、下载、上传）、CPU 与内存、全部不选。
- 页面会按选中的项目自动排版：只选一项时它占满页面；空间不够时先去掉帧率、硬盘等较次要的行，再压缩网速和内存，不会重叠或超出页面；下载与上传共用一行，可只显示其中一个。
- 全部不选时，展开页显示提示和“打开设置”按钮，并且不读取任何数据。没有选中的读数不会被读取，也不会占用资源。
- 没有改过这张表时，展开页与升级前完全一样；旧的显示进程列表、硬盘、功耗与电池、帧率开关也已并入这张表。

## CPU 与 GPU

- CPU 占用率按处理器忙碌时间计算，与 Windows 11 24H2 起的任务管理器一致。
- 有多块显卡时默认显示独立显卡。点击页面上的大号 GPU 读数可以切换到下一块，也可以在“通用 › 显卡”中指定。
- GPU 占用率默认使用显卡驱动的读数（NVIDIA、AMD、Intel），与 nvidia-smi、HWiNFO 一致；驱动没有读数时按任务管理器的方式计算。驱动读数不正确时，可以在“来源 › 显卡占用率”中改为 Windows。

## 硬盘

- 按盘符显示已用空间；页面放不下时，其余盘符合并为一行。
- 只列内置硬盘，不含 U 盘、SD 卡、移动硬盘、网络盘和光驱。

## 温度

“显示温度”默认关闭。读不到的温度不显示。

| 项目 | 来源 |
| --- | --- |
| CPU | 默认来自主板固件提供的 ACPI 热区。许多电脑没有这项数据，有的电脑读到的是主板而不是 CPU 本身的温度 |
| GPU | 显卡驱动报告给 Windows 的温度，与任务管理器相同；没有时改用 NVIDIA、AMD、Intel 驱动自带的接口 |
| 硬盘 | 固态硬盘自己报告的温度。使用 RAID 模式（例如 Intel 快速存储技术）的硬盘不读取温度 |

读不到 CPU 温度时，有两种办法：

- 启用[增强传感器](enhanced-sensors.md)，由 BrimDeck 的传感器服务直接从处理器读取。
- 同时运行 HWiNFO（开启共享内存）或 LibreHardwareMonitor（开启远程网页服务器），BrimDeck 会从中读取。

温度的悬停提示会标明读数来源。

如果读取某一项温度或功率时电脑卡住，BrimDeck 下次启动时会停止读取这一项。已停止的项目列在“展开时”一节中，可以逐项重新开启。

## 整机功耗

页面显示整机功耗（单位 W）及其最近一分钟的曲线，悬停提示列出读数的组成与来源。读数按以下顺序选取：

1. **电脑自带的功率计**：直接测得的整机功耗。只有少数平板和服务器提供。
2. **电池放电功率**：笔记本用电池供电时，电池的放电功率就是整机功耗。
3. **各部件之和**：CPU 功率加上独立显卡的板卡功率（NVIDIA、AMD、Intel）。这是估算值，不含显示器、硬盘、风扇和电源损耗，悬停提示中会注明。

功耗只在系统监控页打开、或刘海与胶囊显示功耗时读取。NVIDIA 显卡的功率通过显卡驱动自带的 nvidia-smi 读取，且只在显卡有负载时读取，不会唤醒休眠的独立显卡。

读不到 CPU 功耗的电脑（例如部分 AMD 电脑）同样可以启用[增强传感器](enhanced-sensors.md)。

## 本机电池

笔记本和平板在功耗一行的右端显示本机电池：

- 电量，以及系统给出时的剩余时间或充满所需时间。接通电源时，电池图标中显示插头。
- 悬停提示中有充放电功率、Windows 电源模式、节电模式和电池健康度（满充容量与设计容量之比）。
- 用电池供电时，电量降到 25% 及以下用预警色，15% 及以下用告警色；接通电源时不变色。

这里显示的是电脑自身的电池。无线鼠标、键盘、耳机等设备的电量见[设备电量支持](devices.md)。

## 帧率

开启“显示帧率”后，页面在网速下方显示前台程序的帧率、程序名称和所在显示器的刷新率；前台程序没有在绘制时，显示最近一个在绘制的程序。

读取帧率需要把当前用户加入 Windows 的“Performance Log Users”组。首次开启时，Windows 会请求一次管理员确认，重新登录 Windows 后生效。帧率只在系统监控页打开、或刘海与胶囊显示帧率时读取。

## 配色

各项读数的颜色默认跟随面板主题，也可以在“通用”一节选择预设配色或自定义。
