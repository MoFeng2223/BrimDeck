## 与 1.2.3 正式版的区别

| 类别 | 改动 | 用户能看到的变化 |
|---|---|---|
| 音乐 | 律动条修复（#150） | 使用 QueMusic 等自定义应用标识的播放器，律动条可以正常跳动 |
| 音乐 | 播放器名称 | 改为显示 Windows 中登记的名称，例如“QueMusic”，不再显示“BroNekoX” |
| 音乐 | 可以不显示封面 | 设置“样式”页的“收起时”和“展开时”各新增一个“显示封面”开关，默认打开。收起时关闭：收起行不显示封面，宽度相应变窄。展开时关闭：音乐页改为左右两栏，左栏显示歌曲信息和律动条，右栏显示歌词 |
| 时间 | 显示秒数 | 新增“显示秒数”开关，默认关闭 |
| 外形 | 切换动画 | 刘海、胶囊、细线之间切换时，凹肩和顶部圆角依次变化，顶部不再在最后一帧突然变圆 |
| 胶囊 | 垂直位置 | 胶囊可以拖到屏幕底部的任务栏中；被任务栏遮住时，自动回到任务栏上方 |
| 系统监控 | 读数宽度 | 功率超过 100 W 时不再被截断；网速在 10 以上时不显示小数，网络读数变窄 |
| 配额 | 目标余额 | 按 API 计费的来源可以设置目标余额，按剩余比例显示用量。例如目标余额 100、剩余 20 时，显示已用 80% |
| 设置 | 来源菜单 | 一次最多显示 10 个来源，其余的滚动查看 |
| 面板 | 滚动条 | 滑块最短 22，不再只显示上半部分 |
| 其他 | 窗口采集 | 修复悬浮窗口无法通过 WGC 采集的问题，例如截图或录屏软件按窗口采集时 |
